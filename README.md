# 此刻 —— 拖延症快速启动引擎

一个针对重度拖延症用户的直接行动工具。核心原则：**不提供建议、不询问状态、不给选择**。打开即命令，倒计时逼迫立即开始一个极小的启动动作。

## 产品定位

用户画像：重度拖延症患者，面对任务时无法启动，容易陷入思维反刍和回避循环。拒绝任何需要先"分析自己"或"制定计划"才能使用的工具。

## 核心原则

1. **零前奏摩擦**：从打开到任务开始不超过3秒。登录后无欢迎页、无"你现在感觉如何"。
2. **不给建议，只下命令**：界面不出现"建议你…""你可以试试…"，只出现祈使句，如"打开文档，只看第一行"。
3. **无选择 paralysis**：用户不浏览列表、不选分类、不评分。系统直接派发单一任务。
4. **启动大于完成**：任务的核心是"让身体先动起来"，而非"做完这件事"。
5. **命令式文案**：任务使用祈使句，句尾不加句号，保持向前的动势。

## 技术栈

- **后端**：Go (Gin) + SQLite
- **前端**：Vue3 + Vite + Pinia + vue-i18n
- **认证**：JWT (access token + refresh token)
- **界面语言**：按浏览器语言自动适配（zh-CN / en-US）

## 快速开始

### 后端

```bash
cd backend
go mod tidy
go run main.go
```

默认监听 `:8080`，SQLite 数据库 `cike.db` 自动创建。

### 前端

```bash
cd frontend
npm install
npm run dev
```

默认开发服务器运行在 `http://localhost:5173`。

## 核心功能

### 用户流程

```
打开应用
    → 未登录 → 登录/注册页（极简：邮箱+密码）
    → 已登录 → 全屏任务卡片立即出现（系统已自动选好任务）
    → 3秒倒计时覆盖层（3 → 2 → 1）
    → 自动进入执行界面（HUD）
    → 倒计时运行（30秒 / 1分钟 / 2分钟 / 3分钟 / 5分钟）
    → 用户点击"完成了"或"跳过"
        ├─ "完成了" → 简短胜利画面 → "继续"或"结束"
        └─ "跳过" → 直接派发新任务（无批评、无记录）
```

### 任务引擎

- **系统预设库**：围绕拖延症"快速启动"设计，覆盖工作启动、家务启动、沟通启动、健康启动、行政启动五大类。
- **用户自定义**：允许添加自定义任务，保存后纳入任务池参与后续派发。
- **派发规则**：获取用户可见的所有任务，排除最近5条执行历史中出现过的任务，随机选择1条。

### API 概览

| 方法 | 路径 | 说明 | 认证 |
|---|---|---|---|
| POST | /api/auth/register | 用户注册 | 否 |
| POST | /api/auth/login | 用户登录 | 否 |
| POST | /api/auth/refresh | 刷新 Token | 否 |
| GET | /api/dispatch | 派发任务 | 是 |
| GET | /api/tasks | 获取任务列表 | 是 |
| POST | /api/tasks | 创建自定义任务 | 是 |
| PATCH | /api/tasks/:id | 更新任务 | 是 |
| DELETE | /api/tasks/:id | 删除任务 | 是 |
| POST | /api/history | 记录执行历史 | 是 |
